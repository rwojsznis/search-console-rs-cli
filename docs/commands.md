# Commands

Generated by `tests/catalog.rs` from the command registry. After changing a
command, run `UPDATE_DOCS=1 cargo test --test catalog docs_commands` and
review the diff. `gsc-cli commands` prints the same as JSON, with every
flag.

Every command is read-only. Each one also calls the OAuth token endpoint
first, unless it is given an access token.

| Command | Requests | Formats | Summary |
|---|---|---|---|
| `query` | `POST /webmasters/v3/sites/{siteUrl}/searchAnalytics/query` | json, jsonl, csv | Clicks, impressions, CTR and position, grouped by dimensions |
| `compare` | `POST /webmasters/v3/sites/{siteUrl}/searchAnalytics/query` | json, jsonl, csv | Compare two periods: each row's metrics, previous metrics and change |
| `sites list` | `GET /webmasters/v3/sites` | json, jsonl | List the properties the credentials can read |
| `sites get` | `GET /webmasters/v3/sites/{siteUrl}` | json, jsonl | Get one property and the permission level on it |
| `sitemaps list` | `GET /webmasters/v3/sites/{siteUrl}/sitemaps` | json, jsonl | List the sitemaps submitted for a property |
| `sitemaps get` | `GET /webmasters/v3/sites/{siteUrl}/sitemaps/{feedpath}` | json, jsonl | Get one sitemap: errors, warnings, submitted and indexed counts |
| `inspect` | `POST /v1/urlInspection/index:inspect` | json, jsonl | Inspect one URL: index status, canonical, last crawl, rich results |
| `auth login` | `POST <token_uri> (the OAuth token endpoint)` | json, jsonl | Log in with a browser and save the credentials |
| `auth status` | `POST <token_uri> (the OAuth token endpoint)`<br>`GET /webmasters/v3/sites` | json, jsonl | Show the credentials in use, and check them end to end |

## Examples

```bash
gsc-cli query --site sc-domain:example.com --dimensions page --filter page:includingRegex:/blog/ --days 28
gsc-cli compare --site sc-domain:example.com --dimensions page --days 7 --sort clicksChange --order asc
gsc-cli sites list
gsc-cli sites get --site sc-domain:example.com
gsc-cli sitemaps list --site sc-domain:example.com
gsc-cli sitemaps get --site sc-domain:example.com https://example.com/sitemap.xml
gsc-cli inspect --site sc-domain:example.com https://example.com/pricing
gsc-cli auth login --client-secret ~/Downloads/client_secret.json
gsc-cli auth status
```
